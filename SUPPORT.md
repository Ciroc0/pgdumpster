# Support

## Bugs

Use the GitHub bug report form with sanitized logs.

Before filing:

```bash
pgdumpster --version
pgdumpster doctor --project-ref <ref>
```

Include the structured error code and environment versions.

## Security issues

Do not open a public issue. Follow `SECURITY.md`.

## Usage questions

Use GitHub Discussions if enabled. Otherwise use a normal issue only when the repository's issue policy permits support questions.

## What maintainers need

Useful:

- exact pgDumpster version/commit;
- OS and Node version;
- Supabase CLI version;
- affected command;
- structured error code;
- sanitized reproduction;
- test-project reproduction when possible.

Never post:

- Personal Access Tokens;
- DB URLs/passwords;
- service-role/secret keys;
- Vault root key;
- Edge secret values;
- S3 credentials;
- decrypted backup data.

## Commercial support

No support is implied by the public source license. Separate commercial licensing enquiries are described in `LICENSING.md`; a commercial license does not imply support unless its written terms say so.
