# Code of Conduct

## Standard

Project participation must stay technical, respectful and useful.

Acceptable behavior includes:

- critique of code, design and decisions;
- disagreement backed by evidence;
- clear security/reliability concerns;
- asking for reproducible cases;
- direct review comments about technical quality.

Unacceptable behavior includes:

- harassment or threats;
- discrimination;
- targeted personal attacks;
- publishing private information;
- intentionally posting credentials, customer data or exploit material that creates avoidable risk;
- spam or persistent off-topic promotion.

## Enforcement

Maintainers may edit, hide or remove content and restrict participation when necessary to protect contributors/users or the security of the project.

Security vulnerabilities should be reported through the private process in `SECURITY.md`, not used as public demonstrations against users.

## Scope

This applies to repository issues, discussions, pull requests and other official project spaces.
